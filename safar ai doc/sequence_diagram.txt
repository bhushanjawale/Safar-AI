
================================================================================
                      SAFAR AI — SEQUENCE DIAGRAM
================================================================================

  PARTICIPANTS (left to right)
  ─────────────────────────────────────────────────────────────────────────────
  User        : End user (browser)
  SPA         : Frontend Single Page App (index.html + js/)
  Router      : js/router.js  (client-side routing)
  AuthManager : js/auth.js    (auth state manager)
  AuthService : js/authService.js (Firebase Auth wrapper)
  Firebase    : Firebase Auth v10.12.2 (external)
  Firestore   : Firebase Firestore DB (external)
  ApiService  : js/api.js     (HTTP client to backend)
  Backend     : Flask app     (backend/app.py, port 5000)
  Gemini      : Google Gemini AI (generativelanguage API)
  Groq        : Groq LLaMA 3.1 8B (api.groq.com)
  Pexels      : Pexels Image API (external)
