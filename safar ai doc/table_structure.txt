
================================================================================
                     SAFAR AI — COMPLETE TABLE STRUCTURE
================================================================================

--------------------------------------------------------------------------------
TABLE 1 : users  (Firestore Collection — PERSISTED)
--------------------------------------------------------------------------------

  +---------------------------------------+
  |                users                  |
  +------------------+--------------------+
  | PK  uid          | string (Firebase)  |
  |     email        | string             |
  |     name         | string             |
  |     isNewUser    | boolean            |
  |     createdAt    | timestamp          |
  +------------------+--------------------+
  |  ↳ preferences   | nested map         |
  |  ↳ wishlist[]    | nested array       |
  +---------------------------------------+

--------------------------------------------------------------------------------
TABLE 2 : users.preferences  (Nested Map inside users — PERSISTED)
--------------------------------------------------------------------------------

  +---------------------------------------+
  |          users.preferences            |
  +------------------+--------------------+
  | FK  uid          | ref → users        |
  |     location     | string             |
  |     budget       | string             |
  |     tripStyle    | string             |
  |     interests[]  | array<string>      |
  |     offbeat      | boolean            |
  +---------------------------------------+

--------------------------------------------------------------------------------
TABLE 3 : users.wishlist[]  (Nested Array inside users — PERSISTED)
--------------------------------------------------------------------------------

  +---------------------------------------+
  |           users.wishlist              |
  +------------------+--------------------+
  | PK  id           | string             |
  | FK  uid          | ref → users        |
  |     destId       | string             |
  |     name         | string             |
  |     image        | string (URL)       |
  |     category     | string             |
  |     addedAt      | timestamp          |
  +---------------------------------------+

--------------------------------------------------------------------------------
TABLE 4 : trips  (Firestore Collection — PERSISTED)
--------------------------------------------------------------------------------

  +---------------------------------------+
  |                trips                  |
  +------------------+--------------------+
  | PK  id           | string             |
  | FK  user_id      | ref → users.uid    |
  |     destination  | string             |
  |     source       | string             |
  |     days         | number             |
  |     budget       | string             |
  |     itinerary_data | map (nested)     |
  |     status       | string             |
  |     created_at   | timestamp          |
  +---------------------------------------+

--------------------------------------------------------------------------------
TABLE 5 : ai_trip_planner  (Nested inside trips.itinerary_data — PERSISTED)
--------------------------------------------------------------------------------

  +---------------------------------------+
  |           ai_trip_planner             |
  +--------------------+------------------+
  | PK  planner_id     | string           |
  | FK  trip_id        | ref → trips      |
  | FK  uid            | ref → users      |
  |     day_number     | number           |
  |     morning_activity | string         |
  |     afternoon_activity | string       |
  |     evening_activity | string         |
  |     meals          | string / map     |
  |     transport      | string           |
  |     cost_estimate  | string           |
  |     tips           | string           |
  |     streaming      | boolean          |
  |     generated_by   | string (Gemini)  |
  +---------------------------------------+

--------------------------------------------------------------------------------
TABLE 6 : flight  (TRANSIENT — UI Only, NOT persisted)
--------------------------------------------------------------------------------

  +---------------------------------------+
  |         flight  ⚡ TRANSIENT          |
  +------------------+--------------------+
  | PK  flight_id    | string             |
  | FK  trip_id      | ref → trips        |
  | FK  uid          | ref → users        |
  |     airline      | string             |
  |     flight_number| string             |
  |     source       | string             |
  |     destination  | string             |
  |     departure_time | string           |
  |     arrival_time | string             |
  |     duration     | string             |
  |     price (INR)  | number             |
  |     class        | string             |
  |     generated_by | string (Groq)      |
  |     transient    | TRUE               |
  +---------------------------------------+

--------------------------------------------------------------------------------
TABLE 7 : hotel  (TRANSIENT — UI Only, NOT persisted)
--------------------------------------------------------------------------------

  +---------------------------------------+
  |          hotel  ⚡ TRANSIENT          |
  +--------------------+------------------+
  | PK  hotel_id       | string           |
  | FK  trip_id        | ref → trips      |
  | FK  uid            | ref → users      |
  |     hotel_name     | string           |
  |     location       | string           |
  |     rating         | float            |
  |     price_per_night| number (INR)     |
  |     amenities      | array<string>    |
  |     room_type      | string           |
  |     total_cost     | number           |
  |     generated_by   | string (Groq)    |
  |     transient      | TRUE             |
  +---------------------------------------+

--------------------------------------------------------------------------------
TABLE 8 : chat_assistant  (SESSION MEMORY ONLY — NOT persisted)
--------------------------------------------------------------------------------

  +---------------------------------------+
  |     chat_assistant  🧠 SESSION        |
  +------------------+--------------------+
  | PK  chat_id      | string             |
  | FK  uid          | ref → users        |
  |     user_message | string             |
  |     ai_response  | string             |
  |     timestamp    | timestamp          |
  |     session_id   | string             |
  |     provider     | string (Groq/Gemini)|
  +---------------------------------------+
  | NOT saved to Firestore                |
  | Cleared on logout                     |
  +---------------------------------------+

================================================================================
                        RELATIONSHIPS OVERVIEW
================================================================================

  users           1 ──── 1     preferences       (nested map in users)
  users           1 ──── N     wishlist[]         (nested array in users)
  users           1 ──── N     trips              (Firestore collection)
  users           1 ──── N     chat_assistant     (session memory only)
  trips           1 ──── N     ai_trip_planner    (nested in itinerary_data)
  ai_trip_planner 1 ──── N     flight             (transient, UI only)
  ai_trip_planner 1 ──── N     hotel              (transient, UI only)

================================================================================
                        PERSISTENCE SUMMARY
================================================================================

  TABLE               PERSISTED?    STORAGE              TRIGGER
  ──────────────────────────────────────────────────────────────────
  users               YES           Firestore            on register
  preferences         YES           Firestore (nested)   on onboarding
  wishlist            YES           Firestore (nested)   on heart click
  trips               YES           Firestore            on save trip
  ai_trip_planner     YES           Inside trips map     on save trip
  flight              NO            UI / transient only  never auto-saved
  hotel               NO            UI / transient only  never auto-saved
  chat_assistant      NO            Session memory       cleared on logout
