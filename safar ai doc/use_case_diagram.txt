================================================================================
  ACTORS
================================================================================

  1. Guest User       — Unauthenticated visitor (not logged in)
  2. Registered User  — Authenticated user (logged in)
  3. New User         — Registered user completing onboarding
  4. Firebase Auth    — External authentication system
  5. Gemini AI        — Google Gemini 1.5 Flash (AI engine)
  6. Groq AI          — Groq LLaMA 3.1 8B (AI engine)
  7. Pexels API       — External image service
  8. Firestore DB     — Firebase Firestore database
