  LEGEND
================================================================================

  +---------------------------+
  |      ClassName            |   Class
  +---------------------------+
  | - privateField : type     |   Attributes
  | + publicField  : type     |
  +---------------------------+
  | + publicMethod() : return |   Methods
  | - privateMethod(): return |
  +---------------------------+

  ──────────  Association       (uses / has reference)
  ◆───────── Composition        (owns / part of)
  ◇───────── Aggregation        (has / contains)
  ──────────▷ Dependency        (depends on)
  ──────────▷ <<uses>>          (calls / invokes)
