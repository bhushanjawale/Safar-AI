SECTION 3 : DATABASE
================================================================================

--------------------------------------------------------------------------------
3.1 DATABASE TECHNOLOGY
--------------------------------------------------------------------------------

  +---------------------------+------------------------------------------+
  | DATABASE                  | Firebase Cloud Firestore (NoSQL)         |
  +---------------------------+------------------------------------------+
  | Type                      | NoSQL Document Database                  |
  | Provider                  | Google Firebase                          |
  | Structure                 | Collections > Documents > Fields         |
  | Realtime                  | Yes — real-time sync supported           |
  | SQL Used                  | No — zero relational/SQL database        |
  +---------------------------+------------------------------------------+

--------------------------------------------------------------------------------
3.2 FIRESTORE COLLECTIONS
--------------------------------------------------------------------------------

  COLLECTION 1 : users
  +---------------------------+------------------------------------------+
  | FIELD                     | PURPOSE                                  |
  +---------------------------+------------------------------------------+
  | uid (PK)                  | Unique user identifier from Firebase Auth|
  | email                     | User email address                       |
  | name                      | Display name                             |
  | isNewUser                 | Triggers onboarding flow                 |
  | createdAt                 | Account creation timestamp               |
  | preferences (map)         | Nested travel preferences object         |
  |   - location              | User home city                           |
  |   - budget                | Preferred budget range                   |
  |   - tripStyle             | Travel style preference                  |
  |   - interests[]           | Array of travel interests                |
  |   - offbeat               | Offbeat destination preference           |
  | wishlist[]                | Array of saved destination objects       |
  +---------------------------+------------------------------------------+

  COLLECTION 2 : trips
  +---------------------------+------------------------------------------+
  | FIELD                     | PURPOSE                                  |
  +---------------------------+------------------------------------------+
  | id (PK)                   | Unique trip identifier                   |
  | user_id (FK)              | Links to users.uid                       |
  | destination               | Trip destination city                    |
  | source                    | User home / departure city               |
  | days                      | Number of trip days                      |
  | budget                    | Trip budget                              |
  | itinerary_data (map)      | Full AI-generated itinerary              |
  | status                    | Trip status (saved/draft)                |
  | created_at                | Trip creation timestamp                  |
  +---------------------------+------------------------------------------+

--------------------------------------------------------------------------------

--------------------------------------------------------------------------------
3.4 DATA PERSISTENCE RULES
--------------------------------------------------------------------------------

  +------------------+------------+------------------+---------------------+
  | ENTITY           | PERSISTED  | STORAGE          | TRIGGER             |
  +------------------+------------+------------------+---------------------+
  | users            | YES        | Firestore        | on register         |
  | preferences      | YES        | Firestore (map)  | on onboarding done  |
  | wishlist         | YES        | Firestore (array)| on heart/save click |
  | trips            | YES        | Firestore        | on save trip click  |
  | ai_trip_planner  | YES        | inside trips map | on save trip click  |
  | flight results   | NO         | UI memory only   | never auto-saved    |
  | hotel results    | NO         | UI memory only   | never auto-saved    |
  | chat messages    | NO         | session memory   | cleared on logout   |
  +------------------+------------+------------------+---------------------+
