Safar AI - Complete Travel Planning Platform

🚀 Quick Start

Install Dependencies
```bash

cd backend
pip install -r requirements.txt
```

Run the Application
```bash

Option 1: Use startup script (Windows)
start.bat

Option 2: Manual start

Backend
cd backend
python app.py

Frontend
python -m http.server 8000
```

Access Application
- Frontend: http://localhost:8000
- Backend API: http://localhost:5000

🔌 API Endpoints (Backend — AI only)

- `POST /api/recommendations` - AI destination recommendations
- `POST /api/nearby` - Nearby destinations
- `POST /api/itinerary/generate` - Generate AI itinerary
- `POST /api/chat` - Chat with AI assistant

🎨 Tech Stack

**Frontend:** HTML5, CSS3, Vanilla JS (ES6 Modules)
**Backend:** Python / Flask (AI routes only)
**Auth & Database:** Firebase (Auth + Firestore)
**AI:** Google Gemini 1.5 Flash
