STEP 8 : PERSISTENCE RULES
================================================================================

  ENTITY              PERSISTED?    WHERE?              WHEN?
  -------             ----------    ------              -----
  users               YES           Firestore           on register
  preferences         YES           Firestore           on onboarding
  wishlist            YES           Firestore           on heart click
  trips               YES           Firestore           on save trip
  ai_trip_planner     YES           inside trips map    on save trip
  flight              NO            transient/UI only   never auto-saved
  hotel               NO            transient/UI only   never auto-saved
  chat_assistant      NO            session memory      cleared on logout
